Java Sockets – TCP und UDP

Netzwerkprogrammierung mit ServerSocket, Socket, DatagramSocket und DatagramPacket

Start JDBC Grundlagen TCP UDP Vergleich

Ziel dieses Kapitels

In diesem Kapitel lernst du, wie Java-Programme über ein Netzwerk miteinander kommunizieren. Dabei werden zwei wichtige Protokolle unterschieden: TCP und UDP.

TCP ist verbindungsorientiert und zuverlässig. Es eignet sich für Anwendungen, bei denen Daten vollständig und in richtiger Reihenfolge ankommen müssen. UDP ist verbindungslos und schneller, garantiert aber nicht, dass jedes Paket ankommt.

Merksatz: TCP verhält sich eher wie ein Telefonat mit Verbindung. UDP verhält sich eher wie das Verschicken einzelner Postkarten.
Theorie

1. TCP und UDP vergleichen

Bevor du programmierst, solltest du die Unterschiede zwischen TCP und UDP erklären können.

Eigenschaft TCP UDP
Verbindung Verbindungsorientiert Verbindungslos
Zuverlässigkeit Bestätigungen, Fehlerkorrektur, geordnete Übertragung Keine Garantie für Zustellung oder Reihenfolge
Datenmodell Stream-orientiert Nachrichten-orientiert mit Datagrammen
Typische Anwendungen HTTP, SMTP, Datenbankzugriffe Audio, Video, Echtzeitanwendungen, Multicast
Überlege: Ist es wichtiger, dass jedes Paket sicher ankommt, oder ist eine geringe Verzögerung wichtiger?

Mögliche Erklärung

TCP wird verwendet, wenn die Daten vollständig, fehlerfrei und in richtiger Reihenfolge ankommen müssen. UDP wird verwendet, wenn Geschwindigkeit und geringe Latenz wichtiger sind als absolute Zuverlässigkeit.

Übung 1

TCP-Server erstellen

Erstelle einen TCP-Server, der auf Port 5000 wartet. Sobald sich ein Client verbindet, soll der Server eine Begrüßung senden und danach die Verbindung schließen.

Aufgabe

public class TcpServer {
    public static void main(String[] args) {
        // 1. ServerSocket auf Port 5000 erstellen
        // 2. Auf Client warten
        // 3. Nachricht an Client senden
        // 4. Verbindung schließen
    }
}
Verwende ServerSocket für den Server und accept(), um auf einen Client zu warten. Zum Schreiben kannst du PrintWriter verwenden.

Musterlösung

import java.io.IOException;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;

public class TcpServer {
    public static void main(String[] args) {
        int port = 5000;

        try (ServerSocket serverSocket = new ServerSocket(port)) {
            System.out.println("Server wartet auf Port " + port + " ...");

            try (Socket clientSocket = serverSocket.accept();
                 PrintWriter out = new PrintWriter(clientSocket.getOutputStream(), true)) {

                System.out.println("Client verbunden: " + clientSocket.getInetAddress());
                out.println("Hallo vom TCP-Server!");
            }

            System.out.println("Verbindung beendet.");
        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}
Übung 2

TCP-Client erstellen

Erstelle einen TCP-Client, der sich mit localhost auf Port 5000 verbindet und die Nachricht des Servers ausgibt.

Aufgabe

public class TcpClient {
    public static void main(String[] args) {
        // 1. Verbindung zu localhost:5000 aufbauen
        // 2. Nachricht vom Server lesen
        // 3. Nachricht ausgeben
    }
}
Starte zuerst den Server. Danach startest du den Client. Der Client verwendet Socket.

Musterlösung

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.net.Socket;

public class TcpClient {
    public static void main(String[] args) {
        String host = "localhost";
        int port = 5000;

        try (Socket socket = new Socket(host, port);
             BufferedReader in = new BufferedReader(
                     new InputStreamReader(socket.getInputStream()))) {

            String message = in.readLine();
            System.out.println("Antwort vom Server: " + message);
        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}
Übung 3

TCP-Echo-Server

Erweitere den TCP-Server so, dass er eine Nachricht vom Client liest und dieselbe Nachricht zurücksendet. Das nennt man Echo-Server.

Für bidirektionale Kommunikation brauchst du einen Eingabestrom und einen Ausgabestrom: BufferedReader zum Lesen und PrintWriter zum Schreiben.

Musterlösung Server

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;

public class TcpEchoServer {
    public static void main(String[] args) {
        int port = 5000;

        try (ServerSocket serverSocket = new ServerSocket(port)) {
            System.out.println("Echo-Server wartet ...");

            try (Socket socket = serverSocket.accept();
                 BufferedReader in = new BufferedReader(
                         new InputStreamReader(socket.getInputStream()));
                 PrintWriter out = new PrintWriter(socket.getOutputStream(), true)) {

                String message = in.readLine();
                System.out.println("Empfangen: " + message);
                out.println("Echo: " + message);
            }
        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}

Musterlösung Client

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.Socket;

public class TcpEchoClient {
    public static void main(String[] args) {
        try (Socket socket = new Socket("localhost", 5000);
             PrintWriter out = new PrintWriter(socket.getOutputStream(), true);
             BufferedReader in = new BufferedReader(
                     new InputStreamReader(socket.getInputStream()))) {

            out.println("Hallo Server");
            String response = in.readLine();
            System.out.println(response);
        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}
Übung 4

UDP-Empfänger erstellen

Erstelle ein Programm, das auf Port 6000 auf ein UDP-Datagramm wartet und den empfangenen Text ausgibt.

Verwende DatagramSocket mit einem Port und ein DatagramPacket mit einem Byte-Array als Puffer.

Musterlösung

import java.io.IOException;
import java.net.DatagramPacket;
import java.net.DatagramSocket;

public class UdpReceiver {
    public static void main(String[] args) {
        int port = 6000;
        byte[] buffer = new byte[1024];

        try (DatagramSocket socket = new DatagramSocket(port)) {
            System.out.println("UDP-Empfänger wartet auf Port " + port + " ...");

            DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
            socket.receive(packet);

            String message = new String(packet.getData(), 0, packet.getLength());
            System.out.println("Empfangen von " + packet.getAddress() + ": " + message);
        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}
Übung 5

UDP-Sender erstellen

Erstelle ein Programm, das eine UDP-Nachricht an localhost auf Port 6000 sendet.

Der Sender benötigt keinen festen lokalen Port. Verwende new DatagramSocket().

Musterlösung

import java.io.IOException;
import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.net.InetAddress;

public class UdpSender {
    public static void main(String[] args) {
        String message = "Hallo per UDP!";
        int port = 6000;

        try (DatagramSocket socket = new DatagramSocket()) {
            byte[] data = message.getBytes();
            InetAddress address = InetAddress.getByName("localhost");

            DatagramPacket packet = new DatagramPacket(data, data.length, address, port);
            socket.send(packet);

            System.out.println("UDP-Nachricht gesendet.");
        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}
Übung 6

InetAddress verwenden

Erstelle ein kleines Programm, das die IP-Adresse des Localhost und die IP-Adresse eines Hostnamens ausgibt.

Verwende InetAddress.getLocalHost() und InetAddress.getByName(...).

Musterlösung

import java.net.InetAddress;
import java.net.UnknownHostException;

public class InetAddressDemo {
    public static void main(String[] args) {
        try {
            InetAddress local = InetAddress.getLocalHost();
            InetAddress host = InetAddress.getByName("orf.at");

            System.out.println("Localhost: " + local.getHostAddress());
            System.out.println("orf.at: " + host.getHostAddress());
        } catch (UnknownHostException e) {
            System.out.println("Host nicht gefunden: " + e.getMessage());
        }
    }
}
Zusatz

Typische Fehler beim Testen

Beim Arbeiten mit Sockets treten häufig dieselben Fehler auf. Diese Übersicht hilft beim Debugging.

Problem Mögliche Ursache Lösung
Connection refused Der TCP-Server läuft nicht oder verwendet einen anderen Port. Zuerst Server starten, danach Client starten.
Programm bleibt stehen accept(), readLine() oder receive() blockiert. Prüfen, ob die Gegenstelle wirklich sendet.
UDP-Empfänger bekommt nichts Falscher Port oder Empfänger wurde nach dem Sender gestartet. Empfänger zuerst starten.
Port bereits belegt Ein anderes Programm nutzt denselben Port. Programm beenden oder anderen Port verwenden.
