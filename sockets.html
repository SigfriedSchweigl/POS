Java Sockets – TCP-Rechner

Eine kleine Client-Server-Übung mit TCP

Start Ziel Übung TCP / UDP

Ziel

In dieser Übung wird ein einfacher TCP-Rechner programmiert. Der Client sendet eine Rechnung an den Server. Der Server berechnet das Ergebnis und sendet es zurück. 

Client sendet: 5 + 3
Server antwortet: Ergebnis: 8

Dabei lernst du die wichtigsten Grundideen von TCP-Sockets: Ein Server wartet auf eine Verbindung, ein Client verbindet sich mit dem Server, beide tauschen Textzeilen aus.

1. Übung: TCP-Rechner

Aufgabe:
Erstelle einen TCP-Server und einen TCP-Client. Der Client sendet eine einfache Rechnung mit zwei ganzen Zahlen und einem Operator. 

5 + 3
10 - 4
6 * 7
20 / 5

Der Server soll die Rechnung auswerten und das Ergebnis an den Client zurücksenden.

Wichtige Idee

TCP arbeitet mit einer Verbindung. Deshalb braucht man beim Server zuerst einen ServerSocket. Sobald sich ein Client verbindet, liefert accept() ein normales Socket-Objekt zurück. 

ServerSocket serverSocket = new ServerSocket(5000);
Socket socket = serverSocket.accept();

Lies die Nachricht des Clients mit readLine() ein. Sende die Antwort mit println(...) zurück. 

BufferedReader in = new BufferedReader(
        new InputStreamReader(socket.getInputStream())
);

PrintWriter out = new PrintWriter(
        socket.getOutputStream(),
        true
);

Der Parameter true bedeutet autoFlush. Die Antwort wird nach println(...) sofort gesendet.

Server: CalculatorServer.java

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;

public class CalculatorServer {
    public static void main(String[] args) throws Exception {
        ServerSocket serverSocket = new ServerSocket(5000);
        System.out.println("Server wartet auf Verbindung...");

        Socket socket = serverSocket.accept();
        System.out.println("Client verbunden.");

        BufferedReader in = new BufferedReader(
                new InputStreamReader(socket.getInputStream())
        );

        PrintWriter out = new PrintWriter(
                socket.getOutputStream(),
                true
        );

        String request = in.readLine();
        String response = calculate(request);

        out.println(response);

        socket.close();
        serverSocket.close();
    }

    private static String calculate(String request) {
        String[] parts = request.split(" ");

        int number1 = Integer.parseInt(parts[0]);
        String operator = parts[1];
        int number2 = Integer.parseInt(parts[2]);

        int result;

        switch (operator) {
            case "+":
                result = number1 + number2;
                break;
            case "-":
                result = number1 - number2;
                break;
            case "*":
                result = number1 * number2;
                break;
            case "/":
                result = number1 / number2;
                break;
            default:
                return "Unbekannter Operator";
        }

        return "Ergebnis: " + result;
    }
}

Client: CalculatorClient.java

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.Socket;

public class CalculatorClient {
    public static void main(String[] args) throws Exception {
        Socket socket = new Socket("localhost", 5000);

        BufferedReader in = new BufferedReader(
                new InputStreamReader(socket.getInputStream())
        );

        PrintWriter out = new PrintWriter(
                socket.getOutputStream(),
                true
        );

        out.println("5 + 3");

        String response = in.readLine();
        System.out.println(response);

        socket.close();
    }
}

Ablauf

  1. Zuerst CalculatorServer starten.
  2. Dann CalculatorClient starten.
  3. Der Client sendet 5 + 3.
  4. Der Server antwortet mit Ergebnis: 8.

Warum braucht man flush?

Ausgaben werden oft zuerst in einem Puffer gesammelt. flush() bedeutet: Jetzt wirklich senden.

Ohne autoFlush müsste man selbst flushen: 

out.println("Ergebnis: 8");
out.flush();

Mit true im Konstruktor passiert das automatisch nach println(...): 

PrintWriter out = new PrintWriter(socket.getOutputStream(), true);

Merksatz:
true aktiviert autoFlush. Dadurch wird eine Zeile sofort an den anderen Socket gesendet.

2. Kurzvergleich: TCP und UDP

Für diese Übung verwenden wir TCP, weil der Client sicher eine Antwort vom Server erhalten soll.

TCP: verbindungsorientiert, zuverlässig, geordnete Datenübertragung.

UDP: verbindungslos, schneller, aber ohne Zustellgarantie.

Merksatz:
TCP verwendet man, wenn Daten sicher ankommen müssen. UDP verwendet man eher, wenn Geschwindigkeit wichtiger ist als Zuverlässigkeit.
