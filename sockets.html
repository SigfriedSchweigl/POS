Java Sockets – TCP und UDP

Grundlagen der Netzwerkprogrammierung mit einer TCP-Rechner-Übung

Ziel

Auf dieser Seite lernst du die Grundidee von Java Sockets kennen. Im Mittelpunkt steht eine einfache TCP-Anwendung: Ein Client sendet eine Rechenaufgabe an einen Server, der Server berechnet das Ergebnis und sendet es zurück.

Dadurch werden die wichtigsten Begriffe wie ServerSocket, Socket, readLine(), println() und flush() an einem kleinen Beispiel verständlich.

1. TCP und UDP kurz erklärt

Java kann über Sockets Daten zwischen Programmen austauschen. Dabei gibt es zwei wichtige Arten der Kommunikation:

TCP ist verbindungsorientiert. Vor dem Datenaustausch wird eine Verbindung aufgebaut. Die Daten kommen zuverlässig und in der richtigen Reihenfolge an.

UDP ist verbindungslos. Pakete werden einfach verschickt. Das ist schneller, aber es gibt keine Garantie, dass ein Paket wirklich ankommt.

2. TCP: Verbindung zwischen Client und Server

Bei TCP gibt es meistens einen Server und einen Client. Der Server wartet auf eine Verbindung. Der Client verbindet sich mit dem Server. 

ServerSocket serverSocket = new ServerSocket(5000);

Socket clientSocket = serverSocket.accept();

accept() wartet so lange, bis sich ein Client verbindet. Danach liefert die Methode ein Socket-Objekt zurück. Über dieses Socket können Server und Client Daten austauschen.

Zum Lesen und Schreiben werden Streams verwendet. Für Textnachrichten sind BufferedReader und PrintWriter gut geeignet. 

BufferedReader in = new BufferedReader(
        new InputStreamReader(socket.getInputStream())
);

PrintWriter out = new PrintWriter(
        socket.getOutputStream(),
        true
);

Der zweite Parameter true beim PrintWriter aktiviert autoFlush. Dadurch wird eine Zeile nach println(...) sofort gesendet.

Ohne autoFlush müsste man selbst flush() aufrufen. flush() leert den Puffer und schickt die Daten wirklich über die Verbindung. 

out.println("Ergebnis: 8");
out.flush();

3. UDP: Datagramme statt Verbindung

UDP arbeitet anders als TCP. Es wird keine feste Verbindung aufgebaut. Daten werden als einzelne Pakete, sogenannte Datagramme, verschickt.

In Java verwendet man dafür hauptsächlich: 

DatagramSocket
DatagramPacket

UDP eignet sich gut für Anwendungen, bei denen Geschwindigkeit wichtiger ist als absolute Zuverlässigkeit, zum Beispiel bei Audio- oder Videodaten.

4. Übung: TCP-Rechner

Schreibe einen TCP-Server und einen TCP-Client. Der Client sendet eine einfache Rechenaufgabe an den Server. Der Server berechnet das Ergebnis und sendet es zurück.

Beispielablauf

Client sendet: 5 + 3
Server antwortet: Ergebnis: 8

Anforderungen

  • Der Server wartet auf Port 5000.
  • Der Client verbindet sich mit localhost und Port 5000.
  • Der Client sendet eine Aufgabe im Format Zahl Operator Zahl.
  • Erlaubte Operatoren: +, -, *, /.
  • Der Server sendet das Ergebnis als Text zurück.

Lies die Eingabe mit readLine() ein und zerlege sie mit split(" "). 

String input = in.readLine();

String[] parts = input.split(" ");

int zahl1 = Integer.parseInt(parts[0]);
String operator = parts[1];
int zahl2 = Integer.parseInt(parts[2]);

Danach kannst du mit if oder switch entscheiden, welche Rechnung ausgeführt wird.

CalculatorServer.java

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;

public class CalculatorServer {
    public static void main(String[] args) {
        int port = 5000;

        try (ServerSocket serverSocket = new ServerSocket(port)) {
            System.out.println("Server wartet auf Port " + port + "...");

            try (Socket socket = serverSocket.accept();
                 BufferedReader in = new BufferedReader(
                         new InputStreamReader(socket.getInputStream())
                 );
                 PrintWriter out = new PrintWriter(
                         socket.getOutputStream(),
                         true
                 )) {

                System.out.println("Client verbunden.");

                String input = in.readLine();
                System.out.println("Empfangen: " + input);

                String result = calculate(input);

                out.println(result);
            }

        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }

    private static String calculate(String input) {
        String[] parts = input.split(" ");

        if (parts.length != 3) {
            return "Fehler: Format muss z. B. 5 + 3 sein.";
        }

        double number1 = Double.parseDouble(parts[0]);
        String operator = parts[1];
        double number2 = Double.parseDouble(parts[2]);

        double result;

        switch (operator) {
            case "+":
                result = number1 + number2;
                break;
            case "-":
                result = number1 - number2;
                break;
            case "*":
                result = number1 * number2;
                break;
            case "/":
                if (number2 == 0) {
                    return "Fehler: Division durch 0.";
                }

                result = number1 / number2;
                break;
            default:
                return "Fehler: unbekannter Operator.";
        }

        return "Ergebnis: " + result;
    }
}

CalculatorClient.java

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.Socket;
import java.util.Scanner;

public class CalculatorClient {
    public static void main(String[] args) {
        String host = "localhost";
        int port = 5000;

        try (Socket socket = new Socket(host, port);
             BufferedReader in = new BufferedReader(
                     new InputStreamReader(socket.getInputStream())
             );
             PrintWriter out = new PrintWriter(
                     socket.getOutputStream(),
                     true
             );
             Scanner scanner = new Scanner(System.in)) {

            System.out.print("Rechnung eingeben, z. B. 5 + 3: ");
            String calculation = scanner.nextLine();

            out.println(calculation);

            String response = in.readLine();
            System.out.println(response);

        } catch (IOException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
    }
}

Warum wird true verwendet?

PrintWriter sammelt Daten zunächst in einem Puffer. Mit true wird autoFlush aktiviert. Dadurch wird nach println(...) sofort gesendet. 

PrintWriter out = new PrintWriter(socket.getOutputStream(), true);

Ohne true müsste man nach dem Schreiben selbst flush() aufrufen: 

out.println(calculation);
out.flush();

Ohne flush() kann es passieren, dass die Nachricht im Puffer bleibt. Dann wartet die Gegenseite auf Daten, obwohl im Programm bereits println(...) aufgerufen wurde.

5. Vergleich: TCP und UDP

TCP verwendet man, wenn Daten zuverlässig ankommen müssen. Beispiele: Webseiten, E-Mails, Datenbankzugriffe.

UDP verwendet man, wenn Geschwindigkeit wichtiger ist als vollständige Sicherheit. Beispiele: Audio, Video, Spiele, Multicast.

Merksatz:
TCP ist zuverlässiger. UDP ist leichter und schneller.
