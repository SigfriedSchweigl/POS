JDBC – Aufgabe 2

Transaktionen und SELECT FOR UPDATE mit Threads

Start JDBC Aufgabe 2

Ziel

In dieser Aufgabe untersuchst du, wie mehrere Threads gleichzeitig auf denselben Datensatz zugreifen.

Dabei lernst du, wie SELECT FOR UPDATE einen Datensatz sperrt, damit eine Transaktion sicher arbeiten kann.

Aufgabenstellung

Erstelle ein JDBC-Programm, das zwei Threads verwendet. Beide Threads sollen Geld von demselben Konto abbuchen.

  • Verwende eine H2-In-Memory-Datenbank.
  • Erstelle eine Tabelle account mit id und balance.
  • Füge ein Konto mit dem Startwert 1000.00 ein.
  • Starte zwei Threads, die gleichzeitig vom selben Konto abbuchen.
  • Verwende SELECT ... FOR UPDATE, um den Datensatz zu sperren.
  • Gib am Ende den finalen Kontostand aus.

Ablauf

  1. Die Tabelle account wird erstellt.
  2. Thread A startet zuerst.
  3. Thread A sperrt den Datensatz mit SELECT FOR UPDATE.
  4. Thread B versucht ebenfalls auf den Datensatz zuzugreifen.
  5. Thread B muss warten.
  6. Nach COMMIT von Thread A kann Thread B weiterarbeiten.

Was bedeutet FOR UPDATE?

Der Zusatz FOR UPDATE sperrt die ausgewählten Datensätze für andere Transaktionen.

Solange die aktuelle Transaktion noch nicht mit COMMIT oder ROLLBACK beendet wurde, müssen andere Threads warten.

Dadurch wird verhindert, dass mehrere Threads gleichzeitig denselben Datensatz verändern.

Beispielausgabe

Eine mögliche Konsolenausgabe könnte so aussehen: 

  Tabelle account erstellt.
  
  Thread A: starte Transaktion
  Thread A: wartet auf Lock...
  Thread A: Lock erhalten
  Thread A: Kontostand = 1000.0
  
  Thread B: starte Transaktion
  Thread B: wartet auf Lock...
  
  Thread A: neuer Kontostand = 900.0 (Änderung: -100.0)
  Thread A: COMMIT
  
  Thread B: Lock erhalten
  Thread B: Kontostand = 900.0
  Thread B: neuer Kontostand = 850.0 (Änderung: -50.0)
  Thread B: COMMIT
  
  Finaler Kontostand: 850.0

Schritt 1: Tabelle erstellen

Die Tabelle braucht eine eindeutige ID und einen Kontostand. Für den Kontostand eignet sich in SQL DECIMAL. 

CREATE TABLE IF NOT EXISTS account (
    id INT PRIMARY KEY,
    balance DECIMAL(10,2)
);

Schritt 2: Testdaten einfügen

Verwende ein Konto mit der ID 1 und einem Startbetrag von 1000.00. 

MERGE INTO account (id, balance)
KEY(id)
VALUES (1, 1000.00);

Schritt 3: Zwei Threads starten

Ein Thread soll zuerst starten. Der zweite Thread startet kurz danach, damit man die Sperre besser beobachten kann. 

Thread t1 = new Thread(() -> withdraw(1, 100, "Thread A", 2000));
Thread t2 = new Thread(() -> withdraw(1, 50, "Thread B", 0));

t1.start();

Thread.sleep(500);

t2.start();

t1.join();
t2.join();

Schritt 4: Transaktion starten

Damit mehrere SQL-Befehle zusammengehören, muss AutoCommit ausgeschaltet werden. 

conn.setAutoCommit(false);

Schritt 5: Datensatz sperren

Mit FOR UPDATE wird der gelesene Datensatz für andere Transaktionen gesperrt. 

SELECT balance
FROM account
WHERE id = ?
FOR UPDATE;

Schritt 6: Kontostand ändern

Lies zuerst den aktuellen Kontostand, berechne den neuen Wert und speichere ihn anschließend mit UPDATE. 

double balance = rs.getDouble("balance");
double newBalance = balance - amount;

String updateSql = """
    UPDATE account
    SET balance = ?
    WHERE id = ?
    """;

Schritt 7: Commit oder Rollback

Wenn alles funktioniert, wird die Transaktion bestätigt. Bei einem Fehler wird sie zurückgenommen. 

conn.commit();
    
conn.rollback();

Schritt 8: Vollständige Musterlösung

package transactions;

import java.sql.*;

public class SelectForUpdateThreads {
    private static final String URL = "jdbc:h2:mem:forupdate;DB_CLOSE_DELAY=-1;LOCK_TIMEOUT=10000";
    private static final String USER = "root";
    private static final String PASSWORD = "root";

    public static void main(String[] args) throws InterruptedException {
        createTable();

        Thread t1 = new Thread(() -> withdraw(1, 100, "Thread A", 2000));
        Thread t2 = new Thread(() -> withdraw(1, 50, "Thread B", 0));

        t1.start();

        Thread.sleep(500);

        t2.start();

        t1.join();
        t2.join();

        printBalance();
    }

    private static void createTable() {
        String createSql = """
            CREATE TABLE IF NOT EXISTS account (
                id INT PRIMARY KEY,
                balance DECIMAL(10,2)
            )
            """;

        String insertSql = """
            MERGE INTO account (id, balance)
            KEY(id)
            VALUES (1, 1000.00)
            """;

        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             Statement stmt = conn.createStatement()) {

            stmt.execute(createSql);
            stmt.execute(insertSql);

            System.out.println("Tabelle account erstellt.");

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    private static void withdraw(
            int accountId,
            double amount,
            String threadName,
            long sleepMillis
    ) {
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD)) {

            conn.setAutoCommit(false);

            System.out.println(threadName + ": starte Transaktion");

            String selectSql = """
                SELECT balance
                FROM account
                WHERE id = ?
                FOR UPDATE
                """;

            try (PreparedStatement selectStmt = conn.prepareStatement(selectSql)) {
                selectStmt.setInt(1, accountId);

                System.out.println(threadName + ": wartet auf Lock...");

                try (ResultSet rs = selectStmt.executeQuery()) {
                    if (rs.next()) {
                        System.out.println(threadName + ": Lock erhalten");

                        double balance = rs.getDouble("balance");
                        System.out.println(threadName + ": Kontostand = " + balance);

                        double newBalance = balance - amount;

                        Thread.sleep(sleepMillis);

                        String updateSql = """
                            UPDATE account
                            SET balance = ?
                            WHERE id = ?
                            """;

                        try (PreparedStatement updateStmt = conn.prepareStatement(updateSql)) {
                            updateStmt.setDouble(1, newBalance);
                            updateStmt.setInt(2, accountId);
                            updateStmt.executeUpdate();

                            System.out.println(threadName + ": neuer Kontostand = " + newBalance + " (Änderung: -" + amount+")"
                        }

                        conn.commit();
                        System.out.println(threadName + ": COMMIT");
                    }
                }

            } catch (Exception e) {
                conn.rollback();
                System.out.println(threadName + ": ROLLBACK");
                e.printStackTrace();
            }

        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    private static void printBalance() {
        String sql = "SELECT balance FROM account WHERE id = 1";

        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {

            if (rs.next()) {
                System.out.println("Finaler Kontostand: " + rs.getDouble("balance"));
            }

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}

Schritt 9: Erwartete Beobachtung

Thread A erhält zuerst den Lock und wartet durch Thread.sleep(...) etwas länger.

Thread B muss warten, bis Thread A die Transaktion mit COMMIT beendet hat.

Erst danach kann Thread B den Datensatz lesen und selbst ändern.

Schritt 10: Kontrollfrage

Überlege, was passieren könnte, wenn beide Threads gleichzeitig denselben alten Kontostand lesen würden.

Ohne saubere Sperre könnten beide Threads denselben alten Kontostand lesen. Dadurch könnte eine Änderung verloren gehen.

Mit SELECT FOR UPDATE wird verhindert, dass beide Threads gleichzeitig denselben Datensatz bearbeiten.
